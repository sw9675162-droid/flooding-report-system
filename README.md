Flood Reporting System

Project Overview

The Flood Reporting System is a Programming Logic project designed to record information about flooding in a community. It collects the flood location, description, and danger level.

Problem Statement

Flooding can damage homes, roads, and properties and can put people’s lives at risk. This project demonstrates a simple way to record flood incidents and identify their danger levels.

Objectives

* To record the location of a flood.
* To collect a description of the flood incident.
* To identify the danger level.
* To demonstrate problem-solving and programming logic skills.

System Inputs

1. Flood location
2. Flood description
3. Danger level

System Process

1. Start the program.
2. Enter the flood location.
3. Enter the flood description.
4. Enter the danger level.
5. Display the flood report.
6. End the program.

Expected Output

The system displays the flood information entered by the user.

Project Tools

* Flowgorithm for designing the program logic.
* GitHub for storing project files and tracking changes.
* Microsoft Word for preparing the assignment report.
